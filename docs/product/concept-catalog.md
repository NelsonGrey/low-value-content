# Low Value Content — Working Concept Catalog

Status: creative development draft. These phrases are not yet fully cleared for trademark, marketplace, or prior-use conflicts.

## Scoring key

- **Launch**: strongest combination of clarity, humor, and wearability.
- **Develop**: promising, but the wording or visual execution needs refinement.
- **Hold**: useful reserve concept or a phrase with a crowded underlying joke.

The first six have editable SVG concept files in `design/prototypes/`. The typography remains live text for easy iteration; convert it to outlines only after choosing the final typefaces and printer specifications. The four expansion examples currently exist as presentation mockups and will need production artwork if selected for printing.
